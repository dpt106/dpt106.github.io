# Role
Personal public website and blog (Jekyll, published via GitHub Pages at https://dpt106.github.io/). Public repo — content here is world-visible, unlike the private ./assistant workspace.

# Publishing
- New posts go in ./_posts/YYYY-MM-DD-title.md with Jekyll front matter (see README.md).
- Commit to a branch and open a PR. Never push to main. Never force-push.
- GitHub Pages builds and deploys automatically on merge to main — no CI/build step to maintain.
