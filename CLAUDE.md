# Role
Personal public website (Jekyll, published via GitHub Pages at https://dpt106.github.io/) for publishing things useful to the user — not a blog. Public repo — content here is world-visible, unlike the private ./assistant workspace.

# Publishing
- New pages are standalone `.md` files (layout: page, with a permalink) linked from index.md — see README.md.
- Commit to a branch and open a PR. Never push to main. Never force-push.
- GitHub Pages builds and deploys automatically on merge to main — no CI/build step to maintain.
